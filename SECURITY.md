## Reporting a Vulnerability

We take the security of the Highly Available AI Microservices (HAMS) platform seriously.

If you believe you have discovered a security vulnerability in any microservice, authentication layer, or infrastructure configuration:

1. **Do not open a public GitHub issue.**
2. Send an email to the project maintainers detailing:
   - Type of vulnerability (e.g., authentication bypass, injection, buffer overflow).
   - Affected service and endpoints.
   - Proof-of-concept steps to reproduce.
   - Impact assessment.
3. You will receive an acknowledgment within 48 hours.
4. Maintainers will coordinate a responsible disclosure timeline and patch release.

Thank you for helping keep our software secure!
